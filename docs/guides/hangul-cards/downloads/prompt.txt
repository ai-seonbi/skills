첨부한 이미지로 한글·영어 양면 따라쓰기 카드를 만들어 주세요.

첨부 이미지의 역할
- 이미지 1: 카드에 넣을 캐릭터입니다. 새로 그리지 말고 원본의 생김새와 색을 유지해 주세요.
- 이미지 2: 한글 앞면의 레이아웃 참고입니다.
- 이미지 3: 영어 뒷면의 레이아웃 참고입니다.

카드 내용
- 한글 이름: [토끼]
- 영어 이름: [Bunny]
- 카드 번호: [01]

앞면과 뒷면의 구성, 여백, 글자 크기, 캐릭터 위치, 두 열의 비율을 참고 이미지와 같게 맞춰 주세요. 카드 전체를 이미지 생성 모델로 다시 그리지 말고 HTML/SVG/CSS처럼 글자와 선을 정확하게 배치할 수 있는 방식으로 만드세요.

앞면
- 왼쪽 위: `따라쓰기 / [번호]`
- 그 아래: 한글 이름
- 오른쪽 위: 이미지 1의 캐릭터
- 본문 왼쪽: `1 순서 보기`
- 본문 오른쪽: `2 따라 쓰기`
- 한글을 음절별 한 줄로 배치
- 왼쪽에는 획순 보기, 오른쪽에는 같은 글자의 점선 따라쓰기

뒷면
- 왼쪽 위: `TRACE / [번호]`
- 그 아래: 영어 이름
- 오른쪽 위: 앞면과 같은 캐릭터
- 본문 왼쪽: `1 Look`
- 본문 오른쪽: `2 Trace`
- 영어는 두 글자씩 한 줄로 배치하고 마지막 홀수 글자는 한 글자로 배치
- 왼쪽에는 쓰는 순서, 오른쪽에는 같은 글자의 점선 따라쓰기

출력 규격
- 작업 크기: 74×104mm
- 완성 크기: 70×100mm
- 사방 2mm 재단 여유
- 중요한 내용은 완성선에서 5mm 안쪽
- 배경은 흰색
- 캐릭터 이미지는 비율을 유지하고 잘리지 않게 배치
- 실제 글꼴을 사용하고 한글과 영어를 이미지로 생성하지 않기
- 앞면 다음에 뒷면이 오도록 2페이지 PDF 만들기
- 앞면과 뒷면을 각각 SVG와 300dpi PNG로도 저장하기

획순 번호와 화살표는 확인 가능한 획순 데이터가 있을 때만 넣으세요. 확인할 수 없다면 임의로 만들지 말고 왼쪽 제목을 `1 글자 보기`로 바꾼 뒤 진한 글자 모양만 보여 주세요.

완료 전 확인
1. 참고 이미지와 결과를 나란히 놓고 여백과 위치 비교
2. 캐릭터가 찌그러지거나 잘리지 않았는지 확인
3. 한글·영어 철자와 글자 순서 확인
4. PDF가 정확히 2페이지인지 확인
5. 페이지 크기, 재단 크기, 안전 여백 확인

먼저 앞면과 뒷면 미리보기를 보여 준 뒤 파일을 만들어 주세요.
