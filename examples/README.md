# 실제 제작 자료와 재현 범위

이 묶음의 스킬은 이번 제작 절차를 다른 작업에 쓰기 쉽게 정리한 배포판입니다. 제작 당시의 개인 도구 설정을 그대로 복사한 것이 아니며 같은 그림이 자동 재현된다고 보장하지 않습니다.

- [시안 비교](https://github.com/ai-seonbi/skills/releases/download/v0.1.0/04-process.png): 실제로 제작했던 스킬 표지의 원본 A·D·E를 A·B·C로 다시 표시했습니다.
- [수정 전후](https://github.com/ai-seonbi/skills/releases/download/v0.1.0/05-process.png): 원본 D의 제목 크기만 53에서 64로 키운 새 재현 예시입니다. 색·곡선·문구·위치는 유지했습니다. 과거 사용자의 실제 수정 요청 이력은 아닙니다.
- [같은 기준의 확장](https://github.com/ai-seonbi/skills/releases/download/v0.1.0/06-process.png): 수정 표지와 기존 D 본문 시안을 함께 보여줍니다. 본문은 선택 이전에 만든 확장안이라 선택 기록을 읽고 나중에 자동 생성한 증거는 아닙니다.

[실제 요청과 따라 하기 문장](../skills/design-guide/references/request-examples.md)을 함께 보세요. 이미지의 내부 표지와 이 자료 바깥의 어두운 카드 프레임은 서로 다른 디자인입니다.
